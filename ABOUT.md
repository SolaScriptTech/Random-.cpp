# About

The C++ Learning Archive preserves small programs and coursework created while learning C++.

## Why this remains a collection

Not every useful exercise needs a standalone repository. Keeping compact programs together makes the profile easier to browse and keeps each repository meaningful. Projects are extracted only when they have a distinct identity, sufficient functionality, or documentation that benefits from an independent home.

## Organization

- `exercises/` contains short, focused programming exercises.
- `projects/` contains larger console programs grouped by topic.
- Finished standalone work is linked from the main README rather than duplicated here.

## Cleanup history

The archive previously included generated executables, object files, build output, duplicate Sea Siren sources, MicMattMoe sources, and an unrelated PowerShell migration tool. Those projects were moved or linked to appropriate repositories, while Git history preserves the original material.
